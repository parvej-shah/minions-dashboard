# Task 119: Dictation Caret Insertion, Top-Right Sticky Mic & Alt+D Shortcut

## Goal
Implement Option A for post editing and all free-text fields:
1. Spoken text inserts/replaces at the current text cursor (`selectionStart`/`selectionEnd`) instead of appending to the end of the post.
2. In multiline text boxes, the dictation mic sits at the top-right and smoothly sticks within the visible viewport bounds when scrolled, so users never need to scroll down to find it, and it never occludes text.
3. Keyboard shortcut `Alt+D` (Option+D on macOS) toggles dictation directly on whichever dictatable field has focus.

## Files to touch
- `src/lib/dictation.ts` (`insertDictation`, `micPlacement`)
- `src/hooks/useDictation.ts` (accept selection getter, pass cursor position to onChange)
- `src/components/ui/GlobalDictation.tsx` (wire selection to useDictation, writeField cursor update, sticky placement, Alt+D shortcut)
- `src/components/ui/DictationMic.tsx` (add Alt+D hint in tooltip/aria)
- `src/lib/dictation.test.ts` (unit tests for insertDictation, caret range, and top-right sticky mic placement)
- `src/test/dictationCaretIntegration.test.ts` (integration tests for caret insertion, sticky placement, and keyboard shortcut)
- `tasks/status.md`
- `docs/decisions/DECISIONS.md`
- `.claude/memory.md`

## Constraints
- Browser speech recognition remains free via Web Speech API (zero server cost, zero API keys).
- Seamless fallback: if no selection is available, append to the end (`base.length`).
- Text wrapping and spacing: automatically manage leading and trailing spaces around inserted speech to avoid character collisions with adjacent words or punctuation.
- Focus and caret must not be lost when clicking the mic button or using `Alt+D`.
- Keep `.claude/memory.md` strictly <= 120 lines, 1-line per session entry.
- All existing 173 test files must continue to pass.

## Acceptance tests
1. `insertDictation`:
   - Empty base returns spoken text.
   - Inserting at end appends with leading space if base does not end with space or newline.
   - Inserting in the middle between words preserves surrounding spaces.
   - Replacing highlighted selection (`start < end`) replaces exactly the selection.
   - Inserting before punctuation (e.g. `.`, `,`, `?`) does not insert a spurious trailing space before the punctuation.
   - Inserting before a word inserts a trailing space so the new speech doesn't merge with following word.
2. `micPlacement`:
   - Sits top-right (not bottom-right) inside a multiline text box.
   - Clamps to visible viewport top when the text box is partially scrolled up.
   - Does not overflow past the bottom of the text box.
3. `useDictation` & `GlobalDictation`:
   - Fires `onChange` with the newly inserted string and the updated cursor position.
   - `writeField` sets `selectionStart` and `selectionEnd` to the end of the inserted spoken phrase.
   - Pressing `Alt+D` toggles dictation when focused in a dictatable field.
