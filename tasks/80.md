# Task 80: Show Carousel Caption When LinkedIn Post Format Is Carousel

## Goal
When a post has its format set to Carousel for LinkedIn (either by default or via the format toggle in CarouselCard), the Captions section under the LinkedIn tab must show the carousel's dedicated caption (`carousel.caption`, written specifically to accompany the document slides) instead of the long article / single-poster variant text (`linkedin_variant`). When the user toggles format to Single poster, it displays the single-poster variant text (`linkedin_variant`). Editing and copying on the LinkedIn tab must always act on the caption for the active format.

## Files to touch
- `src/types/asset.ts`: Add `carousel_active?: boolean` and `carousel_caption?: string | null` to `AssetItem`.
- `src/lib/mappers/asset.ts`: Map `carousel_active` and `carousel_caption` from `asset.carouselSpec`.
- `src/hooks/useEditorialDraft.ts`: Initialize `edited.linkedin` to `activeAsset.carousel_caption` when `carousel_active` is true.
- `src/components/editorial/EditorialStudio.tsx`: Sync `draft.setEditedLinkedin` when `CarouselCard` toggles between Carousel and Single poster or updates its caption.
- `src/components/editorial/social/SocialVariantTabs.tsx`: Ensure the active carousel caption is displayed and copied when `linkedinCarousel` is active.
- `src/test/carouselCaptionInSocialTabs.test.ts`: Unit and acceptance tests verifying caption display, editing, and format switching.

## Constraints
- Do not break existing Facebook, Instagram, or Twitter tabs.
- Do not break single poster copy when Carousel is disabled or non-existent.
- Do not run `vercel link` or `vercel env pull`.
- Keep `.claude/memory.md` within 120 lines budget.
- Full test suite, TypeScript, and lint must pass.
