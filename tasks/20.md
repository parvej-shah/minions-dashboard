# Task 20: Calm redesign — research + direction (UI only)

## Goal
Replace the dark, dense dashboard with a light, Apple-calm UI where a busy owner
makes one decision per screen. This task = research + approved direction; the
rebuild is split into tasks 21+ once the user approves.

Direction board: https://claude.ai/artifact/T631NapCR7U9MuJwrQ2sGY

## Research (2026-11-09, Claude in Chrome)
- apple.com: text #1d1d1f, section #f5f5f7, quiet #86868b (we use #6e6e73 for 4.5:1),
  action blue #0071e3 (we use #0066cc), pill buttons, 17px body, tight letter-spacing,
  one headline + one line + max two buttons per section.
- Pinterest boards: light SaaS dashboards (white pill for active nav, monochrome icons,
  one big number per card), "Today / Good morning" focus screens, segmented
  All/To do/Done filters, social schedulers with week columns + side Edit panel,
  image-first masonry grids.
- Principle sheets: one primary action per view (Fitts/Hick), proximity over borders,
  labels above fields, button text says what happens, decoration only with purpose.

## Proposed structure
- Nav: Today · Ideas · Posts · Brand (billing/team/channels under avatar).
- Today: greeting, one "N posts need your OK → Review now" card, week strip, recent posts.
- Review: post preview is the hero; side: when / where / "Post on Wed 9:00" / Edit / skip;
  checks folded into "Details".
- Ideas: one ordered list (top = written next, with day/time); 'Writing now' card on top; per row only 'Write now' + ⋯ menu (Edit, Write for a set day, Set aside, Delete); filters Up next / Written / Set aside; search.
- Pending posts: Today card + orange count on Posts in the nav + Posts › Needs you (soonest first, Review button each, 'Writing now' placeholder).
- Posts: masonry grid of covers, filter All / Needs you / Scheduled / Posted.
- Light theme only; no confetti, streaks, 3D button edges.
