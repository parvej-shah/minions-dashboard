# Task 127: "Posted" means posted

## Goal
A post that is released at its time always reaches the publisher, and a released post that never reached a channel is shown as "Not posted", never "Posted".

Cause (2026-11-24): bsse1610 and rakibul each had a hand-scheduled post with claims_ok='N'. releaseDuePosts flipped it to PUBLISHED, but 03's publisher reads only claims_ok='Y', so nothing went out and the UI said "Posted".

## Files to touch
- src/services/postSchedule.ts (releaseDuePosts sets claimsOk "Y": SCHEDULED means approved)
- src/lib/posts/library.ts (isPostStuck, groupOf, statusLine)
- src/lib/today.ts (failedPosts includes stuck posts)
- src/components/today/TodayView.tsx (message for a stuck post)
- tests: postSchedule.test.ts, library.test.ts, today test

## Constraints
- Stuck = status PUBLISHED, no published_at, no channel failure recorded, released more than 15 minutes ago (scheduled_for is the release time).
- Within 15 minutes it reads "Going out", not failed.
- No live data changes in this task.

## Acceptance tests
- [x] releaseDuePosts writes claimsOk "Y" with the PUBLISHED flip
- [x] a PUBLISHED post with no published_at, 20 min after scheduled_for, is group "failed" and reads "Not posted · it did not reach your channels"
- [x] the same post 5 min after scheduled_for reads "Going out" and stays "posted"
- [x] a PUBLISHED post with published_at is unchanged ("Posted · Fri 6 Nov")
- [x] failedPosts returns a stuck post
- [x] `npm test`, `npx tsc --noEmit` and lint pass
