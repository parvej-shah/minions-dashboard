# Task 109: Make sure LinkedIn is connected, and stays connected

## Goal
A workspace can't run Autopilot without a working LinkedIn connection, and a lapsed token is noticed before a post fails. One calm line on Today: "Connect LinkedIn" / "Reconnect LinkedIn", one action.

## Files to touch
- src/services/channels.ts, src/lib/linkedin.ts (health: connected / expiring / expired; store expiry at connect)
- src/app/api/auth/linkedin/callback + save (record expiry in client_channels.config)
- src/components/today (one-line nudge), onboarding first-post (optional Connect step), ScheduleSettings (Autopilot disabled with reason)
- 00b/dueTenants: pause Autopilot scheduling when unhealthy

## Constraints
- Skippable in onboarding; Review first works without it (blog only).
- Check health by a cheap LinkedIn call on a schedule, not only by stored expiry.
- No email/push exists; the nudge lives on Today.

## Acceptance tests
- [ ] `npm test`, `npx tsc --noEmit` and lint pass
- [ ] linkedinHealth(row) returns connected / expiring (<7 days) / expired / missing (unit)
- [ ] Autopilot toggle refuses with a reason when not connected
- [ ] unhealthy token: Autopilot drafts go to review, Today shows Reconnect line
