# Task 81: Render Recently Posted as Visual Cards Instead of Plain Text List

## Goal
Replace the plain text list in the "Recently posted" section on the Today page (`TodayView.tsx`) with Apple-grade visual cards. Each card displays the post's visual cover poster (`PostThumb`), top metadata (publishing channel, publication date, status indicator, and live post link if available), headline title, and hook quote.

## Files to touch
- `src/components/today/TodayView.tsx`: Replace plain text `<ul><li>` with responsive card grid (`grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 gap-4 sm:gap-5`), visual poster thumbnail, channel + date metadata, live link, and title/hook.
- `src/test/todayRecentlyPostedCards.test.ts`: Acceptance tests verifying card grid layout, `PostThumb` inclusion, live links, failure styling, and removal of plain list rows.

## Constraints
- Follow Apple-grade design principles from `impeccable` and `ui/README.md`.
- Ensure responsive behavior on mobile (1 column), tablet (2 columns), and desktop (3 columns).
- Fully accessible with semantic headings, links, and keyboard focus states.
- Run `npm test`, `npx tsc --noEmit`, and ESLint before calling done.
- Do not push without user's explicit OK.
