# Task 96: Add-a-design flow in three steps (instructions, import, preview)

## Goal
The "Add a design" modal walks the user through: 1 get the instructions, 2 paste or import an .html file and check it, 3 see a large preview (short/long/empty post) and save. Same look as the other dialogs.

## Files to touch
- src/components/brand/YourDesignsCard.tsx
- src/lib/covers/custom/importFile.ts (+ test)

## Constraints
- The server still checks everything on save; the browser only reads the file as text (<= 200 KB, .html/.htm/.txt).
- One primary button per step; Back goes one step back; editing the HTML drops the old preview.

## Acceptance tests
- [x] importFile refuses wrong type, empty and > 200 KB files, returns the text otherwise
- [x] Step 3 is reachable only after a passing check; Save posts the same HTML that was checked
- [x] tsc, lint, npm test clean

- the parser/contract rules
