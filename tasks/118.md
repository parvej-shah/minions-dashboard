# Task 118: Force channel connection before posting (Option B)

## Goal
If a user has not connected the distribution channel that a post is written for (e.g. LinkedIn), the primary post button in Editorial Studio and Today must not attempt to publish or schedule. Instead, it must enforce connecting that channel first:
1. The button label displays "Connect <Channel> to post" (e.g. "Connect LinkedIn to post").
2. Clicking it opens the channel connection sheet modal, returning directly to the draft upon authentication.
3. The secondary "Post now instead" button is suppressed while the required channel is missing.
4. Publishing and scheduling handlers guard against sending unconnected posts to the publisher.

## Files to touch
- `src/lib/drafts/channelGating.ts` (new pure channel gating helper)
- `src/lib/drafts/channelGating.test.ts` (unit tests for gating logic)
- `src/components/distribution/LinkedInModal.tsx` (support `returnTo` with draft ID)
- `src/components/editorial/ReviewDecision.tsx` (wire missing channel label & connect handler)
- `src/components/editorial/EditorialStudio.tsx` (pass channel configs, handle connect channel, guard publish/schedule)
- `src/components/today/TodayView.tsx` (show "Connect LinkedIn to post" when spotlight post lacks connected LinkedIn)
- `src/test/channelGatingIntegration.test.ts` (component integration tests)
- `tasks/status.md`

- `.claude/memory.md`

## Constraints
- Option B: Button label explicitly states "Connect LinkedIn to post" (or respective channel) rather than "Post now" or "Post on [date]".
- Clicking opens the channel connection flow directly.
- Blog-only posts (where the post override explicitly excludes social channels) must not be blocked.
- Once connected, returning to the draft immediately unlocks the normal post/schedule buttons.
- Follow all working protocol rules: acceptance tests first, full test/typecheck passing, no push without permission.

## Acceptance tests
1. `channelGating.test.ts`:
   - Returns null if the post targets LinkedIn and LinkedIn has `has_credential: true`.
   - Returns `{ key: "linkedin", name: "LinkedIn", actionLabel: "Connect LinkedIn to post" }` when post targets LinkedIn and LinkedIn has `has_credential: false` (or not connected).
   - Returns `{ key: "facebook", name: "Facebook", actionLabel: "Connect Facebook to post" }` when post targets Facebook only and Facebook is not connected.
   - Returns null if the post targets only `blog`.
   - Returns `{ key: "linkedin", name: "LinkedIn", actionLabel: "Reconnect LinkedIn to post" }` when LinkedIn token is expired (`is_expired: true`).
2. `ReviewDecision`:
   - Displays "Connect LinkedIn to post" as the primary button when LinkedIn is not connected.
   - Clicking the button calls `onConnectChannel("linkedin")` instead of `onPublish`.
   - Does NOT show "Post now instead" secondary button when a required channel is missing.
   - When post is SCHEDULED and channel is missing, shows "Connect LinkedIn to post".
3. `EditorialStudio`:
   - Clicking "Connect LinkedIn to post" opens the LinkedIn connection modal with returnTo pointing to the active draft.
   - Calling `handlePublish` or `handleSchedule` when a required channel is missing blocks the action, shows a toast, and opens the connect modal.
4. `TodayView`:
   - When spotlight post targets LinkedIn and LinkedIn health is missing or expired, CTA displays "Connect LinkedIn to post" linking to `/editorial?id=<id>&linkedin=1`.
