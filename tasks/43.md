# Task 43: Direct photo upload under cover preview on Brand page

## Goal
Add an Apple-grade, simple, and clean photo upload control directly under the cover preview in `CoverThemeCard` on the Brand page, allowing founders to update or remove their cover headshot without navigating away to "Photo and more".

## Files to touch
- src/components/brand/CoverThemeCard.tsx
- src/components/brand/CoverThemeCard.test.ts (or unit test)
- tasks/43.md
- tasks/status.md

## Constraints
- Apple-clean minimalism: compact secondary pill button under the preview, subtle loading spinner during upload, graceful error line on validation/network failure.
- File constraints: PNG or JPEG only, max 5 MB.
- Instant feedback: uploads to `/api/media/upload`, saves to `/api/brand`, updates profile state so the sample cover preview automatically redraws with the new headshot.
- "Remove photo" subtle option when a photo exists.
- Fully responsive at desktop and 390px mobile viewports.

## Acceptance tests
- [x] Uploading a valid image file calls `/api/media/upload` and updates `primary_logo_url` in `/api/brand`.
- [x] Rejects files over 5 MB and non-PNG/JPEG with clear error messaging.
- [x] Removing a photo clears `primary_logo_url`.
- [x] TypeScript check and vitest tests pass.

## Do not touch
- prisma/, n8n/, .env*
