# Task 87: Free voice dictation on update boxes

## Goal
People can speak an update instead of typing it. A mic button sits on each box where they give an update; tapping it fills the box live as they talk, tapping again stops. Free: it uses the browser's own speech recognition (Web Speech API), no server, no API key, no cost.

## Files to touch
- src/lib/dictation.ts (+ dictation.test.ts): pure helpers (support check, language, transcript joining, error copy)
- src/hooks/useDictation.ts: start/stop, live interim text, cleanup on unmount
- src/components/ui/DictationButton.tsx: mic button, hidden where unsupported
- src/components/posts/QuickDraftDrawer.tsx, src/components/pulse/WeeklyPulseCard.tsx (answer box), src/components/pulse/ApprovalUpdateAsk.tsx, src/components/brand/MemoryComposer.tsx

## Constraints
- Minimalism: one icon button, no banner, no setup. Hidden entirely in browsers without support (Firefox).
- Spoken text is appended to what's already typed, never replaces it.
- Language follows the browser (navigator.language), fallback en-US.
