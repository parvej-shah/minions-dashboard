# Task 114: Carousel makes one model call, never retries

## Goal
Keep a post under 3 BDT (owner, 2026-11-21). A carousel used to try up to 3
times when its plan failed the checks, and each try costs about $0.023
(≈ 2.9 BDT at 124.35 BDT/USD). Now it makes exactly one call. When that
call fails the checks, the reviewer sees the existing "Make it again, or
LinkedIn posts the cover image" message, and nothing is stored.

## Files to touch
- src/services/carousel.ts, src/services/carousel.test.ts

## Constraints
- A model that is down or out of quota still falls through the chain
  (src/lib/ai/modelChain.ts): a failed call is not billed, so that's not a retry.
- "Make it again" stays: the reviewer can still ask for a new one by hand.

## Acceptance tests
- [x] A plan that fails the checks: the model is called once, nothing is stored, the reviewer sees the plain message
- [x] A good plan: one call, stored (unchanged)
- [x] `npm test`, `npx tsc --noEmit` and lint pass

## Do not touch
- prisma/, n8n/, .env*, src/lib/prompts/carousel.ts
