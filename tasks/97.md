# Task 97: Modern cover fonts, picked per workspace on the Brand page

## Goal
A "Cover font" choice on the Brand page (Bricolage default, plus Anton, Unbounded, Syne, Space Grotesk, DM Serif Display, all SIL OFL). The pick sets the headline face of every new cover and carousel; custom designs may name any of them.

## Files to touch
- src/lib/covers/fonts.ts, fonts/*.ttf + OFL texts, fit.ts (types), render.ts, layouts.tsx (CoverSpec.font)
- src/lib/carousel/render.ts, src/services/cover.ts, carousel.ts, coverPreview.ts
- src/lib/covers/custom/contract.ts, element.tsx, check.ts
- API: src/app/api/brand/cover-font (GET samples, PATCH choice); src/components/brand/CoverFontCard.tsx; brand page
- docs/decisions/DECISIONS.md (supersedes "one face for every tenant")

## Constraints
- Static TTFs only (Satori + our metrics); only OFL fonts; a cover keeps the font it was made with (spec.font).
- Font chosen per render through AsyncLocalStorage so concurrent renders never mix.

## Acceptance tests
- [x] Each font loads, has metrics, and renders a cover; withCoverFont swaps the headline face and the Satori font list
- [x] Unknown font id falls back to Bricolage
- [x] Custom templates accept every cover font name
- [x] tsc, lint, npm test clean

## Do not touch
- body face (Plus Jakarta Sans), colours, n8n
