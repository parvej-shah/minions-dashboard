# Task 116: Can flash or plus models replace the max model?

## Goal
Owner (2026-11-21): not a fan of the max model; flash or plus should be enough;
"you can test some". Run the expensive steps (strategist, writer, carousel)
on the same ideas with each candidate model and put the results side by
side, so the owner picks by reading them. The target is a post under 3 BDT.

## Candidates
- qwen3.8-max-0902: today's large model, the baseline
- qwen3.7-plus: $0.40 / $1.60 per 1M (not on free quota)
- qwen3.7-flash: $0.03 / $0.13 (free quota)
- deepseek-v4.1-flash: $0.20 / $0.40 (today's small model, free quota)

## How
- A throwaway script (deleted after) renders the real prompts from
  src/lib/prompts, calls DashScope with the key in .env.local (never printed),
  and records each step's JSON validity, tokens, seconds and cost.
- 3 made-up ideas shaped like tenant zero's (real-estate voice AI): a lived
  story, an opinion, a reader question. Nothing is read from or written to the DB.
- Carousel: first-try plan validity (`parsePlan`), which matters now that
  there are no retries (task 114). The DB-backed source gate is not run.

## Acceptance tests
- [x] Every candidate runs all 3 ideas through strategist, writer and carousel, or the failure is reported
- [x] Each result shows the cost per post in BDT (124.35 BDT/USD) and first-try carousel validity
- [x] The posts are saved for the owner to read side by side
- [x] No DB access. Reused the existing draft eval (src/test/eval/drafts.ts) with a new --model flag, cost tally and one carousel try, instead of a throwaway script

## Do not touch
