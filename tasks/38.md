# Task 38: Keep the carousel pages as images, for Instagram and Facebook


## Goal
Every carousel render also stores each page as a JPEG (cover first), so the
Studio's Instagram tab can show the whole deck to post by hand, and a later
Facebook multi-photo or Instagram publisher has the files it needs.

## Files to touch
- src/lib/carousel/render.ts (PNG to JPEG), render.test.ts
- src/services/carousel.ts, carousel.test.ts (upload pages next to the PDF, store `pages`)
- src/lib/mappers/asset.ts, mappers.test.ts, src/types/asset.ts (`carousel_pages` on the draft)
- src/components/editorial/social/SocialVariantTabs.tsx, SocialVariantTabs.test.ts (Instagram shows the deck)

## Constraints
- The PDF stays what LinkedIn gets; nothing in n8n changes.
- Pages live in the render's own folder, so `dropReplaced` already deletes them.
- JPEG, 1080x1350: Instagram's API takes JPEG only.

- [x] SocialVariantTabs.test: Instagram shows the deck when the carousel is on, the cover otherwise
