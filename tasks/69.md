# Task 69: Collapsed Draft Reserve by Default & Impeccable Two-Button Hover UI

## Goal
Execute executive design feedback on `/posts`:
1. **Collapsed Draft Reserve by default**:
   - On the `Needs you` tab, the `Draft reserve (N)` section defaults to collapsed (`isReserveExpanded = false`).
   - Clean disclosure control (`Show reserve (N) ▾` / `Hide reserve ▴`) keeps the view calm and focused strictly on the Top 3 curated picks unless explicitly expanded.
   - When collapsed, the reserve grid is hidden.
2. **Two-Button Hover UI with crisp hierarchy & attention structure**:
   - The bottom action area features exactly two buttons:
     - **Primary**: `Schedule · <slot>` (Commanding attention: solid brand background, white text, 1-tap outcome).
     - **Secondary**: `Details` (Calm secondary: soft surface, subtle border, quiet inspection option).
     - Both buttons sit in perfect horizontal harmony with identical height, balanced flex proportions, and tactile active compression.
   - **Delete Action Relocation**:
     - Relocated to the top-right corner of the hover overlay as an unobtrusive icon button (`title="Delete draft"`). This separates destructive intent from the primary outcome path and keeps the bottom buttons clean.
3. **High Readability**:
   - Hover overlay uses `bg-canvas/98 backdrop-blur-md shadow-lg border border-line/40` to guarantee zero contrast bleed-through from the underlying poster.
   - Post title is rendered in high-contrast `text-ink` with tight leading.
   - Hook quote is housed in an elegant quote block (`border-l-2 border-brand/50 pl-3 text-[13px] text-ink/85 italic leading-relaxed`) for effortless executive scanning.
