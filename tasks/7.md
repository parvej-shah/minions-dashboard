# Task 7: Five poster types with their own backgrounds

Decision: DECISIONS.md "Five poster types, each with its own background" (2026-11-09).

## Goal
Covers vary post to post: the type is picked from what each post contains
(a list, parallel items, short punches, the author's own story with a photo),
each type has its own brand-coloured background, and no type repeats twice in
a row. bsse1610's workspace (cmtvi4a7r000104l5kn6bi71o) is the proof.

## Files to touch
- src/lib/prompts/posterShape.ts (new): asks the model for the post's list, grid items and punches
- src/lib/covers/shape.ts (new): parses and checks that answer (no figure the post lacks, word caps, known icons)
- src/lib/covers/posterType.ts (new): picks the type
- src/lib/covers/backgrounds.ts (new): the six backgrounds as SVG from the brand colours
- src/lib/covers/layouts.tsx: new LIST, GRID, PUNCH, PHOTO layouts; backgrounds on all layouts; slide-number-free shared chrome
- src/services/cover.ts: extract the shape once per draft, keep it on the card, pick the type
- src/components/editorial/CoverImageCard.tsx: the new layouts as buttons
- scripts/poster-mix.ts (new): read-only report of which type each of a workspace's posts would get
- tests: src/lib/covers/covers.test.ts, src/lib/covers/poster.test.ts (new)

## Constraints
- Fonts: Bricolage Grotesque and Plus Jakarta Sans (changed 2026-11-09); colours come only from the brand (coverBrand).
- Every text on a background meets 7:1 (body) or 3:1 (large) against what is under it.
- Copy that cannot fit a type drops to the next type, never cut.
- Existing stored covers keep drawing (old layouts still parse).

## Acceptance tests
- [ ] `npm test`, `npx tsc --noEmit` and lint pass
- [ ] parseShape rejects items stating a figure the post lacks, over-long items, unknown icons
- [ ] pickPosterType: never the last type when another fits; PHOTO only with a photo, the author's story and none in the last 3; falls back to HEADLINE/STATEMENT
- [ ] every layout x background renders for the default and a blue palette, text contrast checked in a test
- [ ] scripts/poster-mix.ts on bsse1610's 30 posts uses at least 4 types, no type over 40%, no repeat in a row
