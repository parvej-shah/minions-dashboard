# Task 76: Today Post Cards Precision & Direct Edit-Mode Clickable Surface

## Goal
Make the Today tab post cards significantly more useful and precise for our ICP (busy B2B service founders, agency executives, and brokers) so they can assess post readiness in seconds. Make the entire post card interactive and clickable to open edit mode (`/editorial?id=...`), with a clear hover affordance indicating that the card is clickable, while ensuring inner actions (such as 1-tap Approve, Angle Swap, and Schedule) cleanly stop propagation.

## Constraints
- Single agent working protocol: no delegation to subagents.
- Write acceptance tests before writing the implementation code.
- Entire card must be clickable to navigate to edit mode (`/editorial?id=...`).
- Hovering on the card must visually and textually indicate that the card is clickable (e.g. "Click card to edit ↗", cursor-pointer, elevated hover state, accessible title).
- Inner buttons (such as "Approve for [Slot]", "Swap angle", "Browse all in Posts") must stop propagation so their actions execute without triggering card-level navigation.
- ICP Precision: Display target channels (LinkedIn, Instagram, Facebook), content format (Carousel vs Single poster), topic/pillar tag, and core argument/thesis alongside the hook.
- Scheduled posts on Today and interactive DayTiles in "This week" must also link cleanly to edit mode.
- Maintain memory budget <= 120 lines.
- Run `npm test`, `npx tsc --noEmit`, and ESLint before completion.
- End reply with: Done / Blocked / Needs your decision.
