# Task 88: Voice on every typing field, clearer mic, listening animation


## Goal
Every free-text field in the app (text boxes and plain text inputs) offers the mic, the mic is easy to see when idle, and it shows a simple animation while it listens.

## Files to touch
- src/lib/dictation.ts, src/lib/dictation.test.ts
- src/hooks/useDictation.ts
- src/components/ui/DictationMic.tsx (new, shared look), src/components/ui/DictationButton.tsx
- src/components/ui/GlobalDictation.tsx (new, one mic that follows the focused field)
- src/app/layout.tsx, src/app/globals.css
- the four boxes with an inline mic (mark them `data-no-dictation` so they don't get two)

## Constraints
- Still free: browser speech recognition only; hidden where unsupported.
- Never on password, email, URL, number or other non-prose inputs; opt out with `data-no-dictation`.
- The mic must not take focus from the field (keyboard stays up on phones).
- Animation respects reduced motion.

## Acceptance tests
- [x] `npm test`, `npx tsc --noEmit` and lint pass
- [x] `isDictatable` allows textarea / text / search inputs and refuses password, email, url, number, read-only, disabled and opted-out fields
- [x] `micPlacement` puts the mic bottom-right in a text box and centred on the right in an input, inside the field
- [x] Root layout mounts `<GlobalDictation`; the four inline boxes carry `data-no-dictation`
