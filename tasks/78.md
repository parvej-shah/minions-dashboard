# Task 78: Hide Failed Tab When No Failed Posts Exist

## Goal
Dynamically hide the "Failed" tab in the Posts library Segmented filter bar when there are zero failed posts (`failedCount === 0`). Only reveal the "Failed" tab (with count badge) when failed posts actually exist (`failedCount > 0`). If the user visits or is on `show="failed"` when there are no failed posts, gracefully fall back to the default tab (`needs` or `all`).
