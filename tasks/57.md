# Task 57: Layout tiles fill in one by one, in order

## Goal
"See all" (and the 4 suggested tiles) feel smooth: each tile's own picture is asked for in order, one at a time, so the first fills in after ~one draw instead of all finishing late. No storage, no extra server work.

## Files to touch
- src/lib/covers/pickerThumbs.ts (`tilesToDraw`), src/components/ui/ThumbPicker.tsx
- tests: src/lib/covers/pickerThumbs.test.ts, src/components/ui/ThumbPicker.test.ts

## Constraints
- The server draws one tile at a time; sample pictures stay visible meanwhile. Nothing is stored in R2.
- A tile that failed counts as done so it never blocks the rest.
