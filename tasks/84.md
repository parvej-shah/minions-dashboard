# Task 84: Mobile Bottom Bar Polish (Prominent Center Posts Button) & PWA Install Reliability

## Goal
1. Overhaul the mobile bottom bar (`BottomTabs` in `TopNav.tsx`):
   - Fix broken `grid-cols-4` (leftover from 4-tab days) to 3-tab layout (`Today`, `Posts`, `Brand`).
   - Elevate the middle "Posts" button so it is distinctly bigger, prominent, and ergonomically thumb-friendly compared to the side tabs ("Today" and "Brand").
   - Provide Apple-grade tactile styling (`active:scale-95`, subtle shadow/glow, safe-area inset handling).
2. Fix and harden PWA installability & popup timing:
   - Fix fatal 404 in `public/sw.js` precache (`/manifest.webmanifest` -> `/manifest.json`) which caused service worker installation failure and prevented Chrome from firing `beforeinstallprompt`.
   - Reduce excessive prompt delay (from 25s–30s down to 3s) so phone testers and busy mobile users actually see the install popup.
   - Provide an Android fallback instruction guide when `beforeinstallprompt` does not fire (e.g. non-Chrome mobile browsers, in-app webviews, or missed events).
   - Add a manual install action in `AccountMenu` so users can trigger installation or view instructions anytime without relying on the automatic popup.
