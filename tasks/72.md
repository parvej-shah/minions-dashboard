# Task 72: Autonomous Outcome Architecture (3-Tab Nav & 5-Draft Buffer)

## Goal
Elevate Minions to a 100% autonomous outcome model while preserving the calm, low-cognitive-load design of `Today` (Spotlight) and `Posts` (Curated Shelf) built in tasks 66-71:
1. Simplify top navigation from 4 items to 3 core places (`Today` · `Posts` · `Brand`), removing `Ideas` from `nav.ts`.
2. Redirect `/ideas` to `/posts?show=needs`.
3. Add a quiet "+ Quick draft" action to `Posts` header and a subtle secondary link on `Today` so spontaneous thoughts or links can be drafted immediately into `Posts`/`Today` without managing an idea backlog.
4. Cap automatic drafting at a maximum of 5 unreviewed drafts (`status: "PENDING_REVIEW"`) in `src/services/dueTenants.ts` so busy professionals never return to an overwhelming backlog.
5. Update tests and document the decision in `DECISIONS.md`.
