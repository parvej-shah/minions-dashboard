# Task 42: Show which platform failed to post; no Telegram alert

## Goal
When a post goes out and one platform fails (LinkedIn token expired, Instagram refused, Facebook error), the dashboard says so: "Partly posted · LinkedIn failed" instead of a plain "Posted". The Telegram alert is removed from n8n 03 (user, 2026-11-11: no Telegram needed).

## Files to touch
- src/lib/publishFailures.ts (+ test): reads the stored failures, names the channels, builds the one-line summary
- prisma/schema.prisma + prisma/sql/2026-11-11-publish-failures.sql: assets.publish_failures (jsonb, nullable)
- src/services/instagramPublish.ts (+ test): records Instagram's failure, clears it when a retry succeeds
- src/lib/mappers/asset.ts, src/types/asset.ts: publish_failures on the asset
- src/lib/posts/library.ts (+ test), src/components/today/TodayView.tsx, src/components/editorial/ReviewDecision.tsx: show it
- n8n/workflows/03_review_publisher (+ src/test/n8n/publishing.test.ts): Facebook/LinkedIn errors into publish_failures; Telegram nodes removed

## Constraints
- Status stays PUBLISHED (the engine is unchanged); only the label and the Posted screen change.
- A channel the workspace has off, or a blog it never had, is not a failure.
- Go-live order: SQL, then n8n 03 push, then code push; each needs the user's OK.
