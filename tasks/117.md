# Task 117: Admin UX/UI Overhaul & Visibility

## Goal
Elevate the platform-admin experience to Apple/Swiss-grade craft (Operate mode) and make admin privileges and tools immediately accessible and visible to platform administrators:
1. **Visibility & Quick Access**: Provide a direct, visible "Platform Admin" switch/pill in TopNav and an elevated badge in AccountMenu when `role === "SYSTEM_ADMIN"`.
2. **Platform Admin Chrome**: Modernize the platform-admin header with Post Studio branding, active tab tracking, admin user badge, and "Back to Post Studio" button.
3. **Tenants List**: Add live search, status filter tabs, sort selector, metric cards, and tactile "View as" support session trigger.
4. **Users List**: Add live search, role filter tabs, metric cards, and clean avatar/tenant mapping.
5. **Automations Monitoring**: Enhance scheduler status display, job status indicators, and workspaces auto-drafting search and filter.
6. **Tenant Detail**: Add breadcrumb navigation, direct "View as this tenant" action in header, tabbed sections (Overview, Assets, Pipeline Runs, Ideas, Blog), and polished usage cap editor.
