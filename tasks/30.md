# Task 30: Brand page — basics first, the rest under Advanced


## Goal
Brand opens on the four things a post cannot be written without (what you do,
who you write for, what you post about, what you have done). Everything that
only makes posts sound more like the author sits under Advanced, one row each.
Same data, same routes, same engine.

## What the engine needs (research, 2026-11-10)
| Setting | Where it is read | Group |
|---|---|---|
| Name + what you do (`brand_profile.positioning`) | writer system prompt, `[POSITIONING]` line, every cover | Basic |
| Who you write for (`icp_profiles.who`) | "The ICP" line for strategist and writer; the AUDIENCE rule is derived from it | Basic |
| Topics (TOPICS rules) | brand block; harvest stays on them | Basic |
| Experience (`professional_memory`) | authority gate: an idea must rest on it; "the only first-person material this draft may use" | Basic |
| Reader details (role, company, buyer, pains, decisions, questions, triggers, words) | sharpen ideas; all have working defaults | Advanced |
| Writing samples, tone, phrases, voice rules | few-shot voice match; drafts work without | Advanced |
| Facts you can prove, what sets you apart | lets drafts state facts; unproven ones are flagged anyway | Advanced |
| Words to avoid | a static list already applies | Advanced |
| Idea sources | a general feed is read until one is added | Advanced |
| Cover look | default palette, initials when no photo | Advanced |
| Weekly updates | adds experience over time | Advanced (with experience) |

Setup already asks exactly the basics (focus, audience, one story), so a new
workspace arrives with all four filled.
