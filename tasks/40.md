# Task 40: Instagram format choice (Carousel / Single poster)

## Goal
The Instagram tab in Studio lets the reviewer pick Carousel or Single poster for a draft that has a carousel. The last pick becomes the workspace's default, so posts nobody opens (automated ones) go out the same way.

## Files to touch
- src/lib/carousel/instagramFormat.ts (+ test): one rule for which format Instagram gets
- src/services/instagramFormat.ts (+ test), src/app/api/assets/[id]/carousel/route.ts (PATCH { instagram })
- src/services/carousel.ts (keep the choice when the carousel is redrawn)
- src/services/channels.ts (payload carries instagram_format), src/types/channel.ts, src/types/asset.ts, src/lib/mappers/asset.ts
- src/services/instagramPublish.ts (+ test)
- src/hooks/useChannelSummary.ts, src/components/editorial/EditorialStudio.tsx, src/components/editorial/social/SocialVariantTabs.tsx (+ test)

## Constraints
- No migration: the workspace default lives in client_channels.config (instagram row) as { format }.
- Order: the draft's own pick, else the workspace's last pick, else Carousel.
- A carousel needs 2+ JPEG pages; otherwise Instagram gets the single poster and no choice shows.
- Independent of the LinkedIn carousel switch.
- A draft already on Instagram can't change.

## Acceptance tests
- [x] `npm test`, `npx tsc --noEmit` and lint pass
- [x] instagramFormat.test: draft pick > workspace pick > Carousel; no choice without 2+ JPEG pages
- [x] instagramFormat service test: saves on the draft and as the workspace default; refuses once posted or without a carousel
- [x] instagramPublish.test: LinkedIn on cover still sends the carousel by default; workspace SINGLE sends the cover; draft pick beats workspace
- [x] SocialVariantTabs.test: the Instagram tab shows Carousel / Single poster with the right one ticked, and the preview follows it
