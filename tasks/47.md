# Task 47: Eliminate Native Grey Scrollbars Across Desktop UI

## Goal
Eliminate ugly native grey scrollbars, stepper arrow buttons, and opaque gutters on the desktop Editorial Studio review column and the window edge across all desktop pages, replacing them with a modern transparent-track scrollbar design system and reusable `scrollbar-none` utilities while keeping 100% native scrolling intact.

## Files to touch
- src/app/globals.css
- src/components/editorial/EditorialStudio.tsx
- src/components/editorial/CarouselCard.tsx
- src/components/editorial/social/SocialVariantTabs.tsx
- src/test/scrollbar.test.ts
- tasks/47.md
- tasks/status.md

## Constraints
- Adhere to W3C CSS Scrollbars Module Level 1 standards (`scrollbar-width`, `scrollbar-color`) combined with `::-webkit-scrollbar*` fallback.
- Never set `scrollbar-width` without `scrollbar-color` (prevents Chromium 121+ from dropping WebKit rules and falling back to OS native grey gutters).
- Suppress desktop window edge scrollbar via `scrollbar-width: none; -ms-overflow-style: none;` on `:root, html, body` and `::-webkit-scrollbar { display: none; width: 0; height: 0; }`.
- Transparent scrollbar tracks: scrollbar tracks must have `background: transparent`, eliminating the opaque `#FBFBFD` gutter strip.
- Suppress native stepper arrow buttons (`::-webkit-scrollbar-button { display: none; }`).
- Reusable utilities: define `@utility scrollbar-none` (hiding scrollbars while preserving scrolling) and `@utility scrollbar-subtle` (subtle floating thumb with transparent track).
- Zero scrollability regression: mouse wheel, touchpad swipe, touch gestures, and keyboard navigation must continue working smoothly in Editorial Studio, Brand page, carousel ribbon, and document body.
- No `overflow: hidden` on `html` or `body` on desktop.
- Match existing Tailwind v4 CSS architecture (`@utility`, `@theme`).
- Acceptance tests must be written and committed before or alongside the code.
- `npm test`, `npx tsc --noEmit`, and `npx eslint <touched_files>` must pass with 0 errors.
