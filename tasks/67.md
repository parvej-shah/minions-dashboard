# Task 67: Posts Library Executive Redesign — Curated Top-3 Shelf, Interactive Hover Quick-Peek & 1-Tap Scheduling

## Goal
Transform the Posts library (`/posts`) from a flat, overwhelming 4-column Pinterest wall of 22 screaming posts into a calm, structured executive triage system:
1. **Curated "Top 3 Up Next" Triage Deck**:
   - Spotlights the top 3 unapproved drafts (newest first).
   - Each card displays the 4:5 poster preview, title, 2-line hook quote preview, target channel chips, and two direct actions:
     - `[ ✓ Schedule for [Slot] ]` (1-click inline schedule directly from the card).
     - `[ Review in Studio ]` (link to `/editorial?id=...`).
2. **Interactive Desktop Hover / Focus Quick-Peek (`PostCardPeek`)**:
   - Hovering or focusing over any card in the reserve reveals a floating card with:
     - Opening hook snippet and core message.
     - Word count & channels.
     - Direct 1-click `[ Schedule for Next Slot ]` button.
     - Direct `[ Open in Studio ]` button.
3. **Calm Draft Reserve**:
   - The remaining drafts (4 to N) sit in a clean, lower-density reserve grid.
   - De-escalates visual urgency: replaces screaming coral tags with calm, clean badges.
   - Supports sort order toggle: Recommended / Newest first vs. Oldest first.
4. **Sort Order Alignment**:
   - `postsFor(posts, "needs")` sorts newest first so fresh drafts take precedence over stale accumulated backlogs.
