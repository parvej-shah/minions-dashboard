# Task 49: Desktop cursor scrolling for horizontal thumbnail pickers

## Goal
Enable seamless desktop cursor navigation for horizontal thumbnail pickers (`ThumbPicker.tsx` used in `CarouselCard` and `CoverImageCard`), allowing users to scroll using:
1. Floating left/right navigation arrow buttons (`ChevronLeft` / `ChevronRight`).
2. Mouse wheel translation (hovering and wheeling vertically scrolls the ribbon horizontally).
3. Click-and-drag scrolling (drag with cursor left/right).

## Constraints
- Apple-grade clean minimalism: floating subtle navigation arrows that only appear when there is content to scroll in that direction, with smooth fade/disable.
- Preserves keyboard arrow navigation (`onKeyDown` for left/right arrows).
- Preserves trackpad horizontal gestures and mobile touch swipe.
- Dragging with cursor should not falsely trigger a tile click/selection.
- `npm test`, `npx tsc --noEmit`, and `eslint` pass with 0 errors.

## Acceptance tests
- [x] Left/right navigation arrows render when container has overflow and scroll horizontally on click.
- [x] Left arrow hidden/disabled when scrolled to the start; right arrow hidden/disabled when scrolled to the end.
- [x] Mouse wheel scrolls horizontally when cursor is over the container.
- [x] Click and drag moves the scroll position.
- [x] TypeScript check and vitest tests pass.
