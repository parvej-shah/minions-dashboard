# Task 35: Image-led Facebook caption, an Instagram caption, a plain link comment

## Goal
The text under a Facebook or Instagram image is short and lets the image lead. Facebook opens on the post's hook. Every draft also gets an Instagram caption (copy and post by hand until Instagram publishing exists). The Facebook link comment is one plain line, the same in Studio and in what the publisher posts.

## Constraints
- Facebook caption: first line is the strategist's hook, rewritten for a broader reader; 40 to 110 words.
- Instagram caption: topic keywords in the first 125 characters, no link or URL, 3 to 5 specific hashtags at the end, same fact rules.
- An empty or off-rule Instagram caption is a warning, never a reason to block a draft.
- The Instagram tab shows only when the Facebook tab does (same image, same Meta audience).
- Nothing goes live without the user's OK: the SQL column, n8n 02 and 03 pushes, and the code push, in that order.
