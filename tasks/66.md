# Task 66: Calm Today Tab — Spotlight Single Most Recent Post + 1-Tap Inline Scheduling

## Goal
Transform the Today (`/`) page from an anxiety-inducing backlog counter ("21 posts are ready for your OK") into a calm, focused executive briefing.
1. Always spotlight exactly ONE post: the single most recently generated unposted draft (`PENDING_REVIEW`, newest first).
2. Anchor the decision to the immediate milestone: "Your post for [Tonight at 21:00] is ready."
3. Provide rich in-situ preview (cover image, title, opening hook quote snippet, channels badge).
4. Provide a 1-tap inline `[ ✓ Approve for Tonight 21:00 ]` button that schedules via `POST /api/assets/[id]/schedule` with optimistic state feedback.
5. Provide a calm escape hatch: `Swap angle` (cycles to the next draft in line) and a quiet link to browse the full library in Posts.
6. Suppress the alarmist red numeric counter badge (`21`) from the TopNav / BottomTabs, replacing it with calm restraint.

## Constraints
- Single agent working protocol (`AGENTS.md`): no subagents.
- Write acceptance tests before code.
- Minimum 44px touch targets on buttons.
- Apple-grade clean typography: calm layout, no eyebrow kickers, crisp tactile button states.
- 1-tap scheduling must be optimistic with rollback on network failure.
- Never push without user OK; never run `vercel link`/`vercel env pull`.
- Memory budget $\le 120$ lines.
- End reply with: `Done / Blocked / Needs your decision`.
