# Task 37: Apple-grade interaction feel (spring physics, fluid disclosure, optimistic scheduling)

## Goal
Improve tactile feedback, fluid motion, and perceived performance across the existing UI without changing any design or layout (as requested by user):
1. Fluid Motion & Spring Physics: calibrated Apple spring curves (`cubic-bezier(0.16, 1, 0.3, 1)`), tactile button compression on click (`active:scale-[0.985]`), and spring physics for modals and sheets.
2. Spatial Continuity: fluid accordion grid expansion (`grid-template-rows: 0fr -> 1fr`) for collapsible details without visual jumping or clipping.
3. Optimistic UI: instant transition when scheduling a post (immediate visual update to SCHEDULED with rollback on API failure).
