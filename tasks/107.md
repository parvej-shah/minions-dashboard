# Task 107: Starter set — three posts on a new dashboard

## Goal
When a new workspace's first post is queued, two more drafts start in the background from different angles, so the dashboard shows 2-3 posts to review. They are normal drafts (Review first); nothing posts.

## Files to touch
- src/services/firstPost.ts (queue the extra drafts after the first run starts)
- src/services/starterSet.ts + src/lib/starterSet.ts (pick two ideas from different lanes; reframe the user's story if the harvest has none)
- src/lib/harvestBudget.ts (daily DRAFT cap removed; harvest cap stays)
- tests for each

## Constraints
- Failure of the extras must never fail or delay the first post.
- Runs once per workspace (idempotent on retry); tag the ideas so they are findable.
- Different angles = different lane or different angle of the same story; never the same headline twice.
