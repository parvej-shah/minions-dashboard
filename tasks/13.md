# Task 13: Reviewers choose the carousel style (optional)

## Goal
On the carousel card a reviewer can, optionally, pick one of the seven styles
before the slides are written ("Let the writer choose" is the default), and
switch an existing carousel to another style afterwards. A switch redraws
the same words in the new style with no model call. User asked 2026-11-09.

## Files to touch
- src/lib/prompts/carousel.ts (+ golden unchanged when no style is chosen)
- src/services/carousel.ts, src/services/carousel.test.ts
- src/app/api/assets/[id]/carousel/route.ts (POST takes optional { style })
- src/components/editorial/CarouselCard.tsx (style picker)
- src/lib/carousel/plan.test.ts, docs/decisions/DECISIONS.md

## Constraints
- Choosing is optional; with no choice the writer picks as before.
- A switch is an edit: same gates, same fit; words that don't fit the new
  style are refused with the reason, the old carousel stays. Never cut.
- No schema change (style already lives in the stored plan).
